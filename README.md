# marek-chlazeni-eshop
CO2klima – web pro servis a opravy chladírenských vozů (Marek)

Statický web (HTML/CSS/JS), stačí otevřít `index.html`.

Před spuštěním doplnit v `js/config.js` všechna pole s hodnotou `null`
(na webu jsou vidět jako žluté „[…]“) a v `js/produkty.js` nahradit ukázkové položky.
Podrobnosti v `CLAUDE.md`.
