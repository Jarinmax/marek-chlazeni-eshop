# marek-chlazeni-eshop
CO2klima – e-shop a servis chladírenských vozů (Marek)

Statický web (HTML/CSS/JS): obchod s náhradními díly a zařízeními, košík s objednávkou,
objednávka servisu a poptávka. Stačí otevřít `index.html` v prohlížeči.

- Údaje o firmě, doprava, platby: `js/config.js`
- Produkty: `js/produkty.js`
